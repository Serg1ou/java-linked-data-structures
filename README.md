# Linked Data Structures

This project implements fundamental set operations using pointer-based (linked) data structures in Java.
It focuses on the correct handling of in-place and copy-based algorithms, with special attention to node decoupling and structural integrity.

## Features
- Subset operation (copy-based and in-place)
- Cartesian product of sets
- Difference between sets
- Intersection over multiple linked lists
- Comparator-based tuple handling
- In-place vs. non-mutating implementations

## Notes
